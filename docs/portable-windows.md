# Windows 便携版

## 构建

在 Windows 构建机安装 uv，获取包含 `uv.lock` 的完整源码，在项目根目录运行：

```powershell
powershell.exe -NoProfile -File .\scripts\build-windows.ps1
```

脚本使用锁定依赖安装桌面和构建组件，运行测试，通过后使用 PyInstaller 目录模式打包，检查必要资源并生成 `dist\PrintBridge-windows.zip`。构建机需要可用的带 Tk 支持的 Python；uv 可按项目要求管理 Python 环境。构建产物对应构建机的 Python 架构。

必须在 Windows 上构建 Windows EXE，macOS 上的测试不能替代此步骤。[PyInstaller 官方平台说明](https://pyinstaller.org/en/stable/operating-mode.html)

## 部署

1. 在 Windows 打印电脑安装东芝驱动和 SumatraPDF，先确认本机可以正常打印。
2. 将 ZIP **完整解压**到固定目录，保留 `PrintBridge.exe` 及其 `_internal` 目录，不要只复制 EXE。
3. 双击 `PrintBridge.exe`，在首次配置窗口选择打印机、确认 SumatraPDF 路径和监听设置，然后启动。
4. 按窗口显示的网址从 Mac 访问。网页、设备令牌和 IPP 的操作见项目 README。

目标电脑不需要安装 Python 或 uv。SumatraPDF 和打印机驱动不包含在分发包内，需要单独安装。服务在当前登录用户下运行，电脑需保持开机且用户保持登录；锁屏不等于注销。

若允许局域网访问，按需要在 Windows 防火墙中允许所配置端口的专用网络入站连接。首次启动未签名程序时，应按本机安全策略确认来源；不要关闭系统安全功能。

## 更新与验收

更新前从托盘退出旧程序，再将新 ZIP 完整解压至应用目录。配置和运行时数据保存在用户应用数据目录，独立于程序目录；不要删除该数据目录。若移动了程序目录，需重新设置登录启动入口。

发布前需在 Windows 验证：首次配置、错误路径提示、启动及停止、托盘退出、登录启动、网页静态资源和管理页面、IPP（启用时），并检查中文 PDF、A4、份数、单双面及失败状态。只有人工核对出纸才能确认实际打印；自动测试和构建成功不代表驱动验收通过。


## 首次配置与日常使用

- 默认模拟模式、仅本机访问、IPP 开启。先启动并在“设备令牌管理”中生成令牌，完成模拟上传；再停止服务切换真实打印。
- 打印机下拉框读取 Windows 已安装的本地和连接打印机。SumatraPDF 自动查找常见安装目录和 PATH；未找到时点击“选择文件”。
- 服务启动前检查端口、实际程序文件和打印机是否存在；异常在窗口显示。此检查不会自动打印测试页。
- 启动后配置表单锁定。先停止服务再修改；正在处理的任务结束后才完成停止或退出，不强制杀死打印程序。
- “允许可信局域网访问”对应监听所有 IPv4 地址；窗口显示候选访问地址。多网卡环境请选与 Mac 同网段的地址。防火墙规则需要在 Windows 专用网络中设置，程序不会自动放行。
- 已保存配置后，再次双击会自动启动服务；勾选登录启动时以托盘方式启动。取消勾选后保存并启动即可移除当前用户启动项。移动程序后再次保存以更新启动路径。
- 配置和数据目录为 `%LOCALAPPDATA%\PrintBridge`，可从窗口按钮打开。模拟与真实模式分别使用 `runtime-simulate` 和 `runtime-windows`，令牌也分别生成。
- 旧源码版 `runtime/` 保留原处，不自动导入或删除，避免未确认的旧队列意外出纸。切换到桌面版前停止旧 PowerShell 进程及其登录计划任务。
- 日常更新：托盘退出，替换完整程序文件夹；不要删除用户数据目录。首次运行后的数据库和令牌不会打进分发 ZIP。

源代码调试（仅 Windows）：`uv sync --extra desktop`，然后 `uv run --extra desktop python -m printbridge.desktop`。源代码入口不提供登录启动；正式分发使用 EXE。
